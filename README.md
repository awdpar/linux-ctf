## Getting Started

Download whole repo to find all the hidden flags within. 
To start the application, run A3testgui.py file.

### Prerequisites

* python3
  ```sh
  python3 --version
  ```

### Installation

1. Clone the repo
   ```sh
   git clone hhttps://github.com/awdpar/linux-ctf.git
   ```
2. Check which version of python you have
   ```sh
   python3 --version
   ```
3. Update your packages
   ```sh
   sudo apt update
   ```
4. install python 3
   ```sh
   sudo apt install python3
   ```
5. verify you have latest python 3.14.3
   ```sh
   python3 --version
   ```
